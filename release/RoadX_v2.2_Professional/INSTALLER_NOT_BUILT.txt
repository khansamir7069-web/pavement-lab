INSTALLER NOT BUILT
===================

The installer executable 'RoadX_Professional_v2.2_Setup.exe' could not be automatically compiled during the release creation process because the Inno Setup compiler ('iscc') is not installed or not available on the system PATH.

To manually compile the installer:

1. Download and install Inno Setup (version 6.x recommended) from:
   https://jrsoftware.org/isinfo.php

2. Open the Inno Setup Compiler GUI (or use the CLI tool 'iscc').

3. Open the installer configuration file located in the repository:
   build/installer.iss

4. Verify that the RoadX application has been compiled into the 'dist/RoadX/' directory by PyInstaller:
   pyinstaller build/installer/pyinstaller.spec --clean --noconfirm

5. Click "Compile" in the Inno Setup Compiler GUI, or run the following command from the repository root:
   iscc build/installer.iss

6. The compiled setup installer 'RoadX_Professional_v2.2_Setup.exe' will be generated under the 'build/' folder (or the default output directory configured in your Inno Setup options).
